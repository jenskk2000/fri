# Real-device beta acceptance

Use a development-signed build with the owner's App Group. Simulator results are recorded separately.

- [ ] Complete onboarding on a clean phone, including a past and scheduled stop date. Interrupt onboarding and verify the draft returns.
- [ ] Confirm savings for a known price/count example, record a pouch at an earlier price, undo it, then change the baseline prospectively.
- [ ] Start a pause, lock/close the app, reopen and confirm the timer reflects elapsed time.
- [ ] Add the rectangular Lock Screen widget. Check data after lock/unlock, after a pouch, after undo, and after reboot plus first unlock. Tap through to Progress. Verify discreet mode.
- [ ] Pick a reminder a few minutes ahead. Background the app and verify delivery. Exercise permission denial, allow in Settings, disable, and time-zone behavior.
- [ ] Enter a check-in, edit it, search its note, delete it, inspect milestones after a setback. Check readability with VoiceOver and very large text.
- [ ] Export a backup to Files. Restore on a clean install through the welcome-screen action. Compare dates, inputs, notes, savings and history. Keep the original copy until comparison passes.
- [ ] Import an invalid file; confirm the current plan is unchanged. Restore the prior local version and verify the edited screen closes.
- [ ] Reset the app; confirm onboarding appears, widget has no saved amount, reminder is removed and old local copies cannot be recovered inside FRI. Delete separately exported test copies as needed.
- [ ] Open public privacy/support URLs and verify the developer identity/contact details are correct.

No production account, analytics or payment infrastructure is required for this free version.
