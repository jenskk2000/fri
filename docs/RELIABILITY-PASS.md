# Focused reliability pass

Implement the useful audit findings without expanding the three-feature product.

1. Preserve v1 backups while aligning editable plan rules. Keep valid 500-character general actions; require useful nonempty plans for new edits and normalize legacy empty values on load.
2. Centralize consequential plan, pouch, pause and feedback operations. Preserve captured prices, stable IDs, idempotency and data-before-success behavior.
3. Share current-counting rules without erasing history; retain separate Copenhagen confirmation and original-local-date reflection semantics.
4. Reduce Home's per-second work, repeated history projection, formatter construction and widget payloads. Load backup availability outside view rendering and preserve backup validation on actual restore.
5. Measure one- and five-year synthetic histories before considering asynchronous writes. Preserve immediate onboarding draft durability rather than introducing a loss window solely to reduce writes.
6. Verify core invariants, legacy imports, representative UI flows and the final simulator build. Keep the browser simulator interactive.

Do not do a wholesale architecture rewrite, change the archive schema, remove recovery checks, add services/accounts/analytics, or turn the audit's repeated styling into a large component framework.
